# Breathly Beta 2.3.0-rc.1 for Android

This is a release candidate for testing. The independent package `app.breathly.beta` installs as
**Breathly Beta** alongside the original app; it has separate settings and Health Connect permissions. Minimum Android version: **Android 8.0 (API 26)**.

## Changes

- Finish the current breathing cycle, including the hold after exhaling, before ending a timed session. The timer shows “Last breath” while the cycle finishes.
- Set the preparation countdown from 3 to 60 seconds. Settings are restored after restarting the app.
- Choose whether Android navigation buttons stay visible.
- Add 1-4-2 Ratio, Advanced 5-7-9, Rectangular and Wim Hof Method presets.
- Optionally export completed breathing exercises to Health Connect as mindfulness breathing records. Paused time and the preparation countdown are excluded; active intervals around pauses are recorded separately.
- Include the Android two-digit time-limit display fix, themed app icon and Expo SDK 57 patch updates already on master.

## Limitations

- The new presets address only part of upstream issue #80. Wim Hof includes only the active breathing rhythm, without retention phases or a complete multi-phase protocol.
- Health Connect export requires a compatible Android device, a provider supporting mindfulness records and explicit permission. Android 8.0 alone does not guarantee support. Export is Android-only and does not work in Expo Go.
- Exercises closed before completion are not exported. Export failures are reported in the app; failed records are not queued for later retry. Multiple active intervals can be saved only partially if an individual write fails.
- Resuming a paused exercise restarts its interrupted step. Resuming a paused preparation countdown restarts the selected countdown.
- APK installation or upgrade compatibility depends on the Android package and signing certificate. A build with another signing key cannot update an existing installation of the same package.

The release tag is `android-2.3.0-rc.1-(<actual EAS versionCode>)`. The workflow checks the built APK's package, versionName, versionCode and signing certificate before publication and attaches `Breathly.apk` with `Breathly.apk.sha256`.
